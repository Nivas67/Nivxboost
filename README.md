# ⚡ NivxBoost — Quantum Network Speed & Latency Accelerator

> **NivxBoost** is an ultra-premium, futuristic cyber-glassmorphic web operating system engineered for accelerating network speeds, eliminating jitter, tuning TCP window scaling, optimizing DNS resolvers, and locking in ultra-low gaming latency.

---

## 🌟 Key Features

### 🚀 1. Quantum Turbo Accelerator Matrix
- **One-Click Multi-Vector Acceleration**: Sequentially runs DNS cache flushing, TCP window buffer expansion (64KB), MTU MSS clamping, and Anycast lowest-latency edge node routing.
- **Dynamic HUD Gauge**: Interactive Canvas-rendered rotating circular dial with high-speed particle acceleration effects.
- **Warp Speed Throughput Multiplier**: Boosts available throughput with real-time feedback and duration tracking.

### 🔬 2. Precision Speed Lab (Live Speedometer)
- **Multi-Stream Download & Upload Gauges**: Dual Canvas gauge meters displaying live throughput in Mbps, peak speeds, total data transferred, and bufferbloat queuing latency.
- **Real-Time Latency & Jitter Measurement**: Tests idle latency versus loaded latency with millisecond precision.

### 🌐 3. Global Anycast Node Hopper
- **Interactive 2D World Network Radar**: Visualizes global server nodes across Frankfurt, London, US-East Ashburn, Tokyo, Singapore, and Mumbai.
- **Shortest-Path Auto-Routing**: Single-click auto-routing locks onto the edge node with the lowest ping and 0.00% packet loss.

### ⚡ 4. DNS Optimizer & Cache Purge Suite
- **Live Resolver Benchmark**: Compares latency between Nivx Quantum DoH, Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 (9.9.9.9), and OpenDNS.
- **1-Click Resolver Switch & Local Cache Flush**: Clean slate instant socket flush for lightning-fast lookups.

### 🛡️ 5. Bandwidth Hog Limiter & Process Inspector
- **Active Background App Telemetry**: Identifies high-bandwidth processes (game updates, streaming, background downloads) with instant throttle and termination controls.
- **Bandwidth Reclaimed Counter**: Real-time counter of bandwidth recovered and redirected toward low-latency gaming QOS.

### 🎮 6. One-Click Game Latency Presets
- Custom UDP packet prioritizers and 120Hz tickrate sync profiles for **Counter-Strike 2**, **Valorant**, **Fortnite / Apex Legends**, and **Call of Duty: Warzone**.

### 💻 7. Cyber Telemetry Console & Audit Certificate
- **Interactive Command Terminal**: Supports interactive commands (`help`, `turbo`, `status`, `ping`, `speed`, `dns`, `nodes`, `clear`, `audit`).
- **Exportable Network Audit Certificate**: Generates downloadable JSON audit reports and print-ready verified diagnostic certificates.

### 🔊 8. Sci-Fi Web Audio Synthesizer
- Built-in sound engine synthesizing dynamic harmonic frequencies for clicks, charges, warp acceleration, and success chimes. Includes a quick mute/unmute toggle.

## 🚀 Quick Start & Deployment

You can run NivxBoost locally using any static web server:

### Option 1: Using Python
```bash
python -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.

### Option 2: Using Node / npx
```bash
npx serve .
```

### Option 3: GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` / `root` and click **Save**.
4. Your application will be live within seconds!
